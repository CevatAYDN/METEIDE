# @mete/ui-studio

Studio view (PixiJS). Visual reference: docs/19-studio-view-prototype.md.

Modules: ui-studio

Today the package holds the run view model the Team panel's views share (ADR-051, docs/13): `applyEvent` and `applyAll` fold one run's events into a `TeamView`, each event id applied once, so the history from `mete/events` and the live `mete/event` stream can overlap. Cards are placed by task status alone (`placeOf`: the Board columns of ADR-051). It depends only on `@mete/contracts` and is a library, not a kernel module yet. Agents are folded too (`agents.ts`): each with its role, provider and model, its task, whether it is thinking and the tool it waits on, from the envelope agent id the core sets (shortcut: the events no module publishes yet (`agent.message.sent`, `review.requested`, `vault.note.saved`) have no effect; the request count of a character card waits for an event that names the agent, since the quota module publishes `quota.*` without one; the animations come with tween.js). The fold also keeps the Studio's signals (`signals.ts`: the roles seen approving or reviewing, why the run is paused, and the workspace's spent quotas), and `sceneOf` turns a view into the studio room of docs/13 and ADR-052: desk rows of at most six, lead roles first, one character per role above twelve agents, each idle, thinking, working on a tool or waiting for quota, and the board's notes by column. `paintScene` (`paint.ts`) turns a scene into rects, circles and text in the `@mete/ui-kit` token colours of the theme mode, `layoutOf` (`layout.ts`) gives every note and character its anchor, `effectsOf` (`effects.ts`) turns a live event into the effects of the docs/13 table (moves, bursts, marks, dimming, the final jump), `motionsOf` (`motion.ts`) turns effects into tweens (twelve particles a burst, at most 300 alive, reduced motion keeps only marks), and `createStage` (`stage.ts`) draws the room on a PixiJS canvas and plays the tweens with tween.js, both loaded only then; its ticker runs only while tweens play, at most 60 frames a second, and stops when the panel hides.
