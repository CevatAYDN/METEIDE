The desktop application opens: a Theia 1.76.0 shell on Electron 42.8.1 with the menu bar, file navigator, editor and preferences, titled METE IDE. Build it with `pnpm --filter @mete/desktop bundle` and start it with `pnpm --filter @mete/desktop start`. On Windows the build needs the Visual Studio C++ Build Tools. There is no METE panel yet.
