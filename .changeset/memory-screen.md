A Memory screen shows what METE remembers: the workspace vault's notes (run reports in the journal, lessons, decisions, entities, inbox) newest first, each with its type, title, date, tags, the run it came from and a Private mark, with chips that filter by type and Open, which opens the note in the editor. It opens from the status bar's Memory button, the METE menu or "METE: Open memory"; with no notes it says where notes come from and offers New run (ADR-159).
