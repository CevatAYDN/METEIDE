The METE side view is a view container of collapsible sections (ADR-078): Waiting for you (shown only while a run waits), Runs (a status chip per run; a click shows it in the Team panel; New run), Workspaces (one line per path, cut with an ellipsis) and Quota (a chip per provider, opening the Quota dashboard). Its icon sits above the Explorer, and a layout saved before it gets the view once.
